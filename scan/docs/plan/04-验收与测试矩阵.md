## 六、qqbot/API 集成验收（v2 需求新增）

| # | 操作 | 通过标准 |
|---|------|------|
| T23 | 契约鉴权 | 无 token 调 `/api/analyze` → 401；带 token → 200 且返回 `task_id` |
| T24 | 结果轮询 | `POST /api/analyze` 后按 2s 轮询 `/api/result/{task_id}`：先 `running`，最终 `done` 且负载与 SSE `done` 同构（title/summary/keypoints/files/base_name）；失败路径返回 `error` + 人话 message |
| T25 | QQ 文本摘要 | `/api/summary/{task_id}?max_len=800`：输出 ≤800 字、无表格/frontmatter、含章节 + 前 5 关键点（时间戳）+ 原链；超长正确截断 |
| T26 | 队列与并发 | 同时提交 2 个无字幕视频（触发转录）：第 2 个返回 `queued` 或在 `result` 中显示排队；服务不崩溃、内存不暴涨 |
| T27 | 端到端模拟 bot | 用 HTTP 脚本模拟 bot 全流程：analyze → 轮询 → summary（→ chat 追问 1 轮），全程 ≤10 分钟轮询上限内完成 |
| T28 | 错误转发 | 构造失败场景（无效 URL / 无字幕且音频失败）：`/api/result` 返回人话中文错误，可直接作为 QQ 消息转发 |
