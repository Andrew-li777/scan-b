## 一、目标与约束

| # | 目标 | 约束 |

## 二、核心决策摘要

| 决策 | 内容 | 依据 |
|------|------|------|
| **D1 识别首选：B 站官方 AI 字幕** | `x/player/wbi/v2` 返回的 `ai_status==2` 自动字幕（`ai-zh`），JSON 直读，**零模型下载、零 GPU、国内直连** | B 站大部分无 CC 字幕的视频已有 AI 字幕；现项目代码已请求该端点但未正确优先/过滤，改造成本极低 |
| **D2 兜底识别：faster-whisper + 本地模型** | 模型经 ModelScope（魔搭）/ hf-mirror 一次性下载到 `models/`，之后完全离线；加载一律走本地路径 | 原项目模型走 HF 需代理，是"非常规网络"的主要来源 |
| **D3 嵌入/重排模型同样本地化** | bge-m3、bge-reranker 下载到 `models/`，本地路径加载；懒加载 + 关闭 chromadb 遥测 | 满足 G2 |
| **D4 启动零外网** | 模块级不触发任何模型加载；新增启动自检；缺模型时降级启动并给出明确下载指引 | 满足 G2 |
| **D5 API-first + QQ bot 接入** | 服务保留 Web UI 但以 HTTP API 为对外主契约：结果轮询端点、QQ 文本摘要端点、任务队列与并发闸、Bearer 鉴权；bot 框架（NoneBot2/OneBot 等）由 hermes 侧选择，本项目提供 HTTP 契约 + 示例适配器 | 满足 G3 |
| **D6 YouTube 降级为"网络可达时可用"** | 代码保留但标注不可用；普通网络下 YouTube 不可达，不投入 | 满足 G1 的边界 |

## 三、执行阶段

| 阶段 | 内容 | 估算 |
|------|------|:--:|
| **P0 网络与识别改造**（核心） | B站 AI 字幕优先；transcriber/vectorstore/reranker 本地模型化；download_models.py；启动自检 | 1.5–2 天 |
| **P1 顺带修复** | 多轮对话 history 接通；删除清理 key 对齐；移除只写不读的 cache.set；前端 r.ok/SSE 重连/协议白名单 | 0.5–1 天 |
| **P2 hermes（云服务器）部署配套** | 依赖裁剪（去 nvidia）、CPU 性能调优、systemd 服务、cookie 与鉴权、冒烟脚本 | 1–1.5 天 |
| **P3 qqbot/API 集成适配** | 结果轮询端点、QQ 文本摘要端点、任务队列与并发闸、错误消息人话化、bot 适配示例 | 1–2 天 |
| **P4 验证** | 断网启动验收 + B站识别矩阵 + 回归测试 + qqbot 端到端模拟 | 0.5–1 天 |

合计约 **4.5–7 人天**。
