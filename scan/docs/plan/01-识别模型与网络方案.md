# 01 识别模型与网络方案

> 目标：G1（仅普通网络识别 B 站视频）+ G2（启动零外网）。

---

## 一、识别链路决策树（B 站）

```
URL → BilibiliExtractor.extract()
  ├─ 1. CC 字幕（player/v2，现状已有）─────────── 命中即用（无需模型）
  ├─ 2. AI 字幕（player/wbi/v2，★本次新增首选）── ai_status==2 即用（无需模型、国内直连）
  └─ 3. faster-whisper 兜底（★改造为本地模型）── 音频走 playurl API（现状已有）
```

- **覆盖率预期**：B 站近年大部分视频（尤其影视、知识、资讯类）有 AI 自动字幕；结合已有 CC 字幕，**绝大多数视频不再触发任何模型**，也就同时满足"普通网络"与"无 GPU"两个约束。
- AI 字幕质量 ≈ 自动语音识别结果，对"摘要/重点/RAG"场景足够；如用户对硬字幕+画外音混排场景不满意，再评估在线 ASR 备选（待定项）。

## 二、B 站 AI 字幕接口细节（改造依据）

| 项 | 说明 |
|----|------|
| 端点 | `https://api.bilibili.com/x/player/wbi/v2`（必须走 WBI 签名路径；无签名的 player/v2 **不返回** AI 字幕） |
| 参数 | `bvid` + `cid`（可从 `x/web-interface/view` 的返回中同时取 `aid`，部分风控场景要求 `aid`） |
| 响应 | `data.subtitle.subtitles[]`，关键字段：`lan`（如 `"ai-zh"`）、`ai_status`（**2 = 已完成可用**）、`subtitle_url`（JSON，可能为 `//aisubtitle.hdslb.com/...` 相对地址，现代码已处理 `//` 前缀） |
| 选择策略 | 优先 `ai_status==2` 且 `lan` 含 `zh`（`ai-zh` > `ai-zh-en` > 其他）；其次 CC 字幕；都没有才报"无字幕"走 Whisper |
| 字幕 JSON | `{"body":[{"from":0.0,"to":3.5,"content":"..."}]}` — 与现有解析完全兼容，`SubtitleEntry` 直接复用 |

**现项目差距**（`src/extractors/bilibili.py`，重构时修正）：
1. `_fetch_subtitles` 先试 player/v2 再试 wbi/v2，但 wbi 路径仅在 v2 返回空时才走——顺序应反过来或并行尝试；
2. `_sign_wbi` 的 mixin key 用 `sub_key[:4] + img_key[:4]` 近似拼接，建议按官方 `mixinKeyEncTab` 重排表完整实现（[bilibili-API-collect](https://gitea.s1f.ren/shiran/bilibili-API-collect) 有现成表），并保留"签名失败回退无签名"的容错；
3. 未按 `ai_status` 过滤，可能选中未就绪条目。

## 三、模型清单与国内获取源

| 模型 | 用途 | 体积 | 国内直连源 | 加载方式（改造后） |
|------|------|:--:|------|------|
| `faster-whisper-small` (CTranslate2) | 兜底转录 | ~460MB | ModelScope `pengzhendong/faster-whisper-small`；备选 `HF_ENDPOINT=https://hf-mirror.com` | `WhisperModel(str(models_dir/"whisper-small"))` — **传本地目录** |
| `faster-whisper-medium`（可选） | 更高精度 | ~1.5GB | 同上 | 同上 |
| `BAAI/bge-m3` | 向量嵌入（RAG） | ~2.2GB | ModelScope `BAAI/bge-m3`；备选 hf-mirror | `SentenceTransformer(str(...))` 本地目录 |
| `BAAI/bge-reranker-v2-m3` | RAG 精排 | ~1.2GB | ModelScope；备选 `maidalun1020/bce-reranker-base_v1`（更小） | `CrossEncoder(str(...))` 本地目录 |

> 依据：ModelScope（魔搭）为国内直连平台，`pip install modelscope` 后 `snapshot_download(repo_id, local_dir=...)` 即可（断点续传）；hf-mirror.com 通过环境变量 `HF_ENDPOINT` 全局生效，faster-whisper / sentence-transformers 底层 huggingface_hub 均会读取。两者都**只需要普通网络**。

## 四、模型下载脚本设计（新增 `scripts/download_models.py`）

```
用法: python scripts/download_models.py [--all|--whisper|--embedding|--reranker]
行为:
  1. 目标目录: models/{whisper-small, bge-m3, bge-reranker-v2-m3}
  2. 源优先级: 本地已有(跳过) → ModelScope(snapshot_download, resume) → hf-mirror(HF_ENDPOINT)
  3. 每次下载后写 models/.manifest.json {model, version, sha256, source, date}
  4. 幂等: 已存在且 manifest 匹配则跳过
```

配套：`scripts/check_offline.py`（或 FastAPI 启动钩子）：
- 检查 4 个模型目录 + manifest；
- 全齐 → 正常启动（此后**断网可用**）；
- 缺 whisper → 降级启动（无字幕视频直接报错并提示下载命令）；
- 缺 embedding/reranker → RAG 禁用（页面提示），分析管道其余功能不受影响；
- 缺 LLM key → 分析阶段报错（启动不受影响）。

## 五、启动零外网设计（G2 落地清单）

1. **`src/rag/vectorstore.py`**：模块级不再实例化 embedding function；`get_or_create`/`search` 首次调用时从 `models/bge-m3` 本地路径构建（懒加载 + 进程级单例）。
2. **`src/rag/reranker.py`**：`_get_reranker()` 改从本地路径加载（已是懒加载，仅改路径）。
3. **`src/transcriber.py`**：`_get_model()` 改从 `models/whisper-small` 本地路径加载（已是懒加载）；`_inject_cuda_path` 在无 GPU 时直接跳过（不再探测 CUDA 目录）。
4. **chromadb 遥测**：`PersistentClient(path=..., settings=Settings(anonymized_telemetry=False))`，消除启动时的后台网络尝试。
5. **导入链审计**：确认 `src.web.server` → `pipeline` → `transcriber/vectorstore` 全链路模块导入阶段**零网络零模型加载**（现状已基本满足，改造后补一个 `import` 冒烟测试：断网 import 全模块不抛错、不挂起）。
6. **超时防护**：所有模型加载统一包 `try/except` + 超时，失败即降级而非让请求挂起（现状有部分裸加载）。

## 七、P0 实测记录（2026-07，新项目落地时验证）

1. **WBI 签名修复**：`/x/web-interface/nav` 在未登录时返回 `code=-101` 但仍携带 `wbi_img`。原实现（及旧项目）按 `code != 0` 直接放弃取密钥，导致无 cookie 时**签名永远失败**、AI 字幕主链路静默失效。修复：只看 `wbi_img` 字段在场与否。修复后实测 `w_rid` 正常生成、wbi/v2 返回 200。
2. **风控 IP 下 AI 字幕为空**：从数据中心/风控 IP 无 cookie 访问 wbi/v2，热门视频 **20/20 返回 `subtitles: []`**（`data.subtitle` 结构正常：`allow_submit/lan/subtitles`）。结论：**AI 字幕可用性依赖网络环境**——住宅网络通常直接可用，风控 IP 必须配 `BILIBILI_COOKIES`；代码回退链（→ player/v2 → Whisper）已覆盖此场景。
3. **个别视频 62002**（稿件不可见）：部分视频无 cookie 时 view 接口直接拒绝（4 个样本中 2 个），与字幕无关，属 B 站风控常态；配 cookie 后缓解。
4. 纯函数回归 84/84 通过；全模块 import 冒烟通过（懒加载后导入阶段零 chromadb 写库、零模型加载）。

## 六、边界说明

- **YouTube**：普通网络下不可达。代码保留（不删），文档与 UI 标注"需网络可达环境"；`match()` 行为不变，避免破坏用户既有 vault 数据。
- **LLM（DeepSeek API）**：运行时仍需外网——属"其他问题待定"，不在 G2 范围；若未来要求全离线，见 README 待定项 1。
