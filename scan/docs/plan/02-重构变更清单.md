## P3 — qqbot/API 集成适配（v2 需求新增）

> 原则：**本项目只负责 HTTP 服务端契约**；QQ bot 框架（NoneBot2 / OneBot-NapCat / Lagrange 等）由 hermes 侧决定并维护，本项目提供一个最小示例适配器验证契约。

| # | 文件 | 改动 | 估算 |
|---|------|------|:--:|
| 3.1 | `src/web/server.py` | **结果轮询端点** `GET /api/result/{task_id}`：任务完成后返回与 SSE `done` 相同结构的 JSON；进行中返回 `{"status":"running"}`；失败返回 `{"status":"error","message":...}`；轮询间隔建议 2–5s | 1.5h |
| 3.2 | `src/web/server.py` | **QQ 文本摘要端点** `GET /api/summary/{task_id}?max_len=800`：纯文本/Markdown 精简（无表格、无 frontmatter），含：一句话总结 + 章节列表 + 前 5 关键点（时间戳）+ 原链；适配 QQ 消息长度限制（截断 + "…"） | 1.5h |
| 3.3 | `src/web/pipeline.py` | **任务队列与并发闸**：全局信号量——转录（Whisper）同时 ≤1、LLM 并发 ≤2–3；排队任务返回 `{"status":"queued"}`；防云服务器 CPU/内存过载 | 2h |
| 3.4 | `src/web/pipeline.py` | **错误消息人话化**：pipeline 异常按阶段映射为 bot 可直发的中文提示（如"该视频无可用字幕且音频下载失败"）；错误统一走 `{"status":"error","message":...}` 结构 | 1h |
| 3.5 | `deploy/hermes/qqbot_adapter.py`（示例） | 最小适配器：收到 QQ 消息（含 B 站 URL）→ `POST /api/analyze` → 轮询 `/api/result` → 发 `/api/summary` 文本；框架无关（仅演示 HTTP 调用顺序） | 3h |
| 3.6 | `docs/api-contract.md` | HTTP API 契约文档：端点、鉴权、请求/响应示例、轮询与错误约定——供 bot 开发者对接 | 1h |
