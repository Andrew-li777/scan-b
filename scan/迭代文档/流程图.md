## 一、字幕提取（3 级回退策略）

```mermaid
flowchart TD
    URL[/"输入视频 URL"/] --> MATCH{"URL 平台匹配?"}
    
    MATCH -->|"youtube.com / youtu.be"| YT_API["youtube-transcript-api<br/>获取 CC 字幕"]
    MATCH -->|"bilibili.com/video/BV"| BL_API["B站开放 API ×2<br/>player/v2 + player/wbi/v2"]
    MATCH -->|"space.bilibili.com/.../lists"| BL_LIST["yt-dlp BilibiliCollectionList<br/>展开 BV URL → 批量串行解析"]
    BL_LIST --> BL_API
    MATCH -->|"不匹配"| ERR1(["❌ 不支持该平台"])
    
    YT_API --> YT_OK{"有CC字幕?"}
    YT_OK -->|"✅ 有"| YT_PASS["获取成功"]
    YT_OK -->|"❌ 无"| YTDLP["yt-dlp 下载 SRT 字幕"]
    
    YTDLP --> YTDLP_OK{"解析成功?"}
    YTDLP_OK -->|"✅ 有"| YT_PASS
    YTDLP_OK -->|"❌ 无"| WHISPER
    
    BL_API --> BL_OK{"有CC字幕?"}
    BL_OK -->|"✅ 有"| BL_PASS["获取成功"]
    BL_OK -->|"❌ 无<br/>（大部分B站视频）"| BL_AUDIO["playurl API 获取音频直链<br/>CDN 下载携带 Cookie 防 403"]
    BL_AUDIO --> WHISPER
    
    WHISPER["🎤 Whisper 语音识别<br/>(language=None 自动检测)"]
    WHISPER --> GPU_DETECT{"GPU 可用?<br/>(RTX 3050 Ti + CUDA)"}
    GPU_DETECT -->|"✅ 是"| GPU_MODEL["medium + cuda + int8_float16<br/>~5min/13min视频"]
    GPU_DETECT -->|"❌ 否"| CPU_MODEL["small + cpu + int8<br/>~10min/26min视频"]
    GPU_MODEL --> WHISPER_PASS
    CPU_MODEL --> WHISPER_PASS["转录: SubtitleEntry[]<br/>含 start/end/text"]
    
    YT_PASS --> DONE_EXT(["字幕提取完成"])
    BL_PASS --> DONE_EXT
    WHISPER_PASS --> DONE_EXT
    
    style WHISPER fill:#e67e22,color:#fff
    style GPU_MODEL fill:#00b894,color:#fff
    style DONE_EXT fill:#27ae60,color:#fff
    style ERR1 fill:#e74c3c,color:#fff
```

## 三、LLM 智能分析（动态 Map-Reduce）

```mermaid
flowchart TD
    SUBS[/"预处理字幕"/] --> SPLIT{文本长度?}

    SPLIT -->|"≤ 15K 字"| SHORT["全量送入 LLM"]
    SPLIT -->|"> 15K 字"| CHUNK["动态分块<br/>━━━━━━<br/>~15K 字/块，最多12块"]

    CHUNK --> CHUNK_LLM["每块摘要<br/>(2048 tokens, 实时进度推送)"]

    CHUNK_LLM --> MANY{"块数 > 6?"}
    MANY -->|"是"| DOUBLE["双层 Map-Reduce<br/>━━━━━━<br/>3块→1组摘要<br/>组摘要→最终摘要"]
    MANY -->|"否"| MERGE["合并摘要"]

    DOUBLE --> FINAL["最终摘要<br/>(4096 tokens)"]
    MERGE --> FINAL
    SHORT --> FINAL

    FINAL --> S_OUT["输出:<br/>• 一句话总结<br/>• 章节划分(带时间戳)<br/>• 详细摘要"]

    SUBS --> KP["KeyPoint 提取<br/>━━━━━━<br/>长视频: 分块提取→去重→Top20<br/>短视频: 全量一次提取<br/>json_schema 约束输出"]

    KP --> KP_OUT["输出:<br/>[{timestamp, content,<br/>importance: 1-5}]<br/>5-20 条重点"]

    S_OUT --> DONE_LLM(["LLM 分析完成"])
    KP_OUT --> DONE_LLM

    style DOUBLE fill:#e67e22,color:#fff
    style S_OUT fill:#0984e3,color:#fff
    style KP_OUT fill:#0984e3,color:#fff
```

## 六、Web 实时通信（SSE 事件类型）

```mermaid
sequenceDiagram
    participant B as 浏览器
    participant S as FastAPI 后端
    participant Q as Queue(线程安全)
    participant T as 后台线程

    B->>S: POST /api/analyze?url=xxx
    S->>Q: 初始化队列
    S->>T: 启动后台线程
    S-->>B: { task_id }

    B->>S: GET /api/progress/{task_id} (SSE)
    S->>Q: 监听队列 (timeout=900s)

    T->>Q: status: "提取字幕中..."
    Q-->>S: event: status
    S-->>B: 状态行更新

    T->>T: 提取 → 预处理
    T->>Q: status: "预处理完成，AI分析中..."
    Q-->>S: event: status
    S-->>B: 状态行更新

    T->>Q: status: "摘要: 3/8 段"
    Q-->>S: event: status
    S-->>B: 分段进度

    T->>Q: download: "45"
    Q-->>S: event: download
    S-->>B: 下载进度条 45%

    T->>Q: transcribe: "72"
    Q-->>S: event: transcribe
    S-->>B: 转录进度条 72%

    T->>Q: done: {json_result}
    Q-->>S: event: done
    S-->>B: 渲染结果 + 下载 + Chat + 刷新侧栏
```

### SSE 事件类型

| event | 含义 | 前端行为 |
|-------|------|----------|
| `status` | 阶段状态文本 | 更新 #statusLine |
| `download` | 下载进度百分比 | 显示下载进度条 |
| `transcribe` | 转录进度百分比 | 显示转录进度条 |
| `done` | 单视频分析完成 | 渲染 4 Tab + 下载链接 + 刷新侧栏 |
| `error` | 单视频出错 | 显示错误信息 |
| `batch_progress` | 批量任务进度 | 更新 `done/total`，若 `failed>0` 显示失败数量 |
| `batch_done` | 批量任务结束 | 刷新侧栏；全成功显示绿色，有失败显示红色 |
