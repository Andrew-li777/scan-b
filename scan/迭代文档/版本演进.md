## 版本总表

| 版本 | 时间 | 目标 | 关键新增 / 修复 | 验证结果 |

| **v1.7** | 2026-10-17 | 长视频概览质量 | 章节时间戳真实化（时间进 Map + 单块不走 Map-Reduce） | 长视频概览时间戳非 0 |

## 版本关系图

```
v0.x  Windows 原型（2026-06）
  └─ 主链路：下载 → 字幕/转录 → LLM 总结 → 多格式输出
        │
        ▼ （迁 Linux，内存治理成为主线）
v1.0  服务器适配 ──────────────────────────────┐
  ├─ v1.1 暖纸 UI + 访客模式 + 哈希外置         │ 安全基线
  ├─ v1.2 mermaid 自托管 + SEO/安全头           │ 国内可达性
  ├─ v1.3 批量解析（合集/分P）                  │ 功能面
  ├─ v1.4 分P 展示与批量稳定性                  │
  ├─ v1.5 下载/导出修复                         │ 可用性
  ├─ v1.6 三角色 + 行级可见性 + 配额 + 审查整改 │ 权限与资源
  ├─ v1.7 长视频时间戳                          │ 质量
  └─ v1.8 传输压缩 + 接口拆分 + 鉴权缓存        ┘ 性能（减字节）
        │
        ▼
     待办：③ CF 按角色分 Cache Key（RTT 层）
```

**并行线说明**：v1.6 是一个「时间段」而非单次发布——10-11 的 RAG 修复、10-15 的三角色/配额/审查整改
是三条并行工作线，按提交日期归入同一版本；其中任一条的细节见《问题记录》对应条目（#61–#74）。
